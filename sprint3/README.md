# Kampüs Etkinlikleri — Sprint 3

AliEfe Demirci — 2416501079

## Yapılanlar

- Altı etkinlik data.js dosyasında tanımlandı.
- Etkinlik kartları JavaScript ile oluşturuldu.
- Ana sayfada tarih ve saate göre sıralanan ilk iki etkinlik gösterildi.
- Arama ve kategori filtresi birlikte çalışacak şekilde hazırlandı.
- Detay sayfası URL'deki id bilgisine göre dolduruldu.
- Geçersiz veya eksik id için hata mesajı eklendi.
- Form alanları JavaScript ile kontrol edildi.
- Güncelleme formu seçilen etkinliğin bilgileriyle dolduruldu.
- Geçerli form bilgileri JSON olarak ekranda ve Console'da gösterildi.
- Dar ekranlar için duyarlı yerleşim korundu.
